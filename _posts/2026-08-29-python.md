本当に今更なのですが、"Python Enhancement Proposals" というものがあるらしく、

そういえば、RFC を引き合いにだそうと思ったのですが、最近はそういうのは関係なくなったので、すっかり忘れてしまって、

と間違えて、なんかおかしいなとか思って AI 検索の人に教えてもらいました。なんか、はずかしいことばかりやっていますね。

で、PEP なのですが、今回の主題の
[PEP 723](https://peps.python.org/pep-0723/)
は該当のファイルを読んでもらうことにして、なんか、ほかにもいろいろ面白そうなものがあるので、びっくりしました。ちょっと目についたあたりだと、
[python コードのスタイルガイド](https://peps.python.org/pep-0008/)
とか
[The Zen of Python](https://peps.python.org/pep-0020/)
とかが目をひきました。

他には、おなじような路線の話として Rust の cargo の話もしました。ようするに、ちゃんとプロジェクトを初期化しないといけないのはちょっと堅苦しいといった感じのことです。それについても教えてもらいました。

これは
[cargo-eval](https://crates.io/crates/cargo-eval)
というクレートをインストールすればいいみたいです。

たとえば、これを使って "the book" の第 2 章にある乱数生成の外部パッケージを使うと



とやるだけで、乱数がつかえるようになります。cargo だけだと、rand を使うだけなのに、いちいちディレクトリを掘ってプロジェクトを初期化するみたいなことをするので、ちょっと敷居がたかかったのですが、それもこれで解決です。

さらにすごいのは、

~~~
#!/usr/bin/env cargo eval --
//! ```cargo
//! [dependencies]
//! rand = "0.8.5"
//! ```
use rand::Rng;

fn main() {
   let num = rand::thread_rng().gen_range(1..=100);
   println!("{num}");
}
~~~

などと shebang つきでプログラムを書いて、python スクリプトのようにして実行できる点です(注：これについては、下記の注記も見てください)。もちろん、いきなり動的型付き言語になるわけではなく、コンパイルのための時間はかかるようですが、なんというか気分的にはだいぶいいかんじです。

そういえば、この前から
[proconio](https://crates.io/crates/proconio)
とか使いたかったのですが、これで気軽につかえそうですね。

~~~ Rust
// cargo-deps: proconio = "0.6.0"
use proconio::input;

fn main() {
   input! {
       n: usize,
       m: usize,
       a: [i32; n],
   }

   println!("{}", a[m-1]);
}
~~~

これは、長さ N の配列 A が与えられたときに、`A[M-1]` をプリントするプログラムです。
競技プログラミングの問題でありがちな形式で、stdin から N, M, A などが与えられときに、Rust で読み込むのが楽になります。
これを標準のライブラリだけで対処するとなると結構面倒でしたが、これで楽勝ですね。

**(2026/08/29 追記)** gemini さんによると
~~~
#!/usr/bin/env cargo eval --
~~~
のように shebang で `env` を使った場合、OS によっては複数の引数を解釈しない場合があると言われました。
その場合には、`env` コマンドを使わず、`cargo-eval` コマンドを直接指定したほうがいいそうです。
