[前回の投稿](https://eiu2.github.io/2026/08/28/uv.html)
の中で、uv のパッケージの扱いについて、書いたところ、またしても
gemini さんから教えてもらいました。

まだドキュメントをちゃんと読んでない段階の疑問だったのですが、最近ドキュメントを読むのも億劫になってきて、教えてもらって大変にありがたかったです。以前に、AI を使うようになってから生活が変ったということを書いたかと思いますが、uv にしてもそうですが、こういったことを教えてくれることが多くて大変に助かっています。

で、せっかく教えてもらったので、教わったことを整理しつつ、ブログの投稿にまとめてみようと思いました。

まず、たとえば `openpyxl` を使いたいとします。

従来 Mac でこれを使おうと思ったら anaconda あたりをダウンロードするか、brew の python を使うぐらいしかなかったかと思います。ちなみに `openpyxl` は Excel ファイルの読み書きをするためのパッケージです。

それが、uv をつかうと、次のようなスクリプトを書いて

~~~ python3
# /// script
# dependencies = [
#    "openpyxl",
# ]
# ///
from openpyxl import *

wb = Workbook()
ws = wb.active

for n in range(1,10):
    ws["A"+str(n)] = n

wb.save('xxx.xlsx')
~~~

端末から

~~~
$ uv run testuv.py
~~~

とかやればすんでしまいます。

あるいは、単に

~~~ python3
from openpyxl import *

wb = Workbook()
ws = wb.active

for n in range(1,10):
    ws["A"+str(n)] = n

wb.save('yyy.xlsx')
~~~

であっても

~~~
$ uv run --with openpyxl test2.py
~~~

でも上手くいきました。それから、interactive に

~~~
$ uv run --with openpyxl python3
Python 3.14.7 (main, Aug 14 2026, 15:24:10) [Clang 22.1.3 ] on darwin
Type "help", "copyright", "credits" or "license" for more information.
>>> from openpyxl import *
>>> wb = Workbook()
>>> ws = wb.active
>>> ws["A1"] = "foo"
>>> ws["B2"] = 1234
>>> wb.save("aaa.xlsx")
>>> quit()
$
~~~

でもいけました。

これは本当にありがたいことです。生活が変わりそうです。前の投稿で、

> パッケージはプロジェクト毎にいれるみたいなので、私みたいに、`/tmp` あたりにちょこちょことスクリプト書いて実行するみたいないい加減な使い方をしていると、ちょっと敷居がたかいです。

と書きましたが、思ったとおりのことができそうで、感激です。

あと、ダウンロードしたパッケージですが、いちおうどこかに保存されていて、その都度ダウンロードするわけではないみたいです。

ちなみに、gemini さんのアドバイスをちょっと引用すると、

> 実は PEP 723（Inline Script Metadata）という規格があり、uv はこれに標準対応しています。

ということでした。以前にも PEP という言葉を見た気がして、ちょっと調べてみました。

本当に今更なのですが、"Python Enhancement Proposals" というものがあるらしく、
python コミュニティに向けた python の新機能の説明や提案のようなものがまとめられています。
なんか、
[RFC](https://www.rfc-editor.org/)
に似ていて、同じような感じに番号がついていて整理されています。

そういえば、RFC を引き合いにだそうと思ったのですが、最近はそういうのは関係なくなったので、すっかり忘れてしまって、
[RTFM](http://www.catb.org/jargon/html/R/RTFM.html)
と間違えて、なんかおかしいなとか思って AI 検索の人に教えてもらいました。なんか、はずかしいことばかりやっていますね。

で、PEP なのですが、今回の主題の
[PEP 723](https://peps.python.org/pep-0723/)
は該当のファイルを読んでもらうことにして、なんか、ほかにもいろいろ面白そうなものがあるので、びっくりしました。ちょっと目についたあたりだと、
[python コードのスタイルガイド](https://peps.python.org/pep-0008/)
とか
[The Zen of Python](https://peps.python.org/pep-0020/)
とかが目をひきました。
