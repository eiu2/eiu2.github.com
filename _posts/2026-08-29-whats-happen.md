直前の投稿なんですけど、つまり、
[Inline Script Metadata](https://eiu2.github.io/2026/08/29/script.html)
の投稿ですね。

昨日の晩に 29 日になってすぐに markdown のファイルを投稿したのですが、朝になってもレンダリングされていないので、なにかファイル中に変なことをしたかな？ と思ってしらべたのですが、特に何もわかりませんでした。

ファイルを消去して、別ファイル名でアップロードしたり、怪しいコードブロックを削除したりもしましたが、だめでした。

そこで、最後に問題のなさそうな最初の数段落だけにして投稿したら、ちゃんと html に変換されて、ブラウザにもちゃんと表示されました。そこで、少しずつ、少しずつファイルの内容を付け加えてコミットしたのですが、結局最後までやっても何のお咎めもなくアップロードできました。

特に github に障害があったわけでもないし、いったい、何が起きたのでしょうか？

**(2026/08/29 追記)** この投稿を gemini さんに見てもらったら、いろいろと原因を推測してもらって、その中に UTC との時差の関係でまだ「未来の投稿」としてあつかわれたためということでした。「未来の投稿」は jekyll が markdown を html に変換してくれないそうです。
実際、午前 9 時をすぎたら投稿できるようになった。というか、投稿したものが html に変換されるようになったので、時差が原因みたいでした。

対策としては `_config.yml` に `future: true` を追加するといいみたいです。
