いままで使っていた MacBook の Lid の配線がおかしくなったらしく、Lid をあけても画面が真っ暗になったままになることが多くなりました。開けたり閉じたりを繰り返して、うまい具合のところで止めると画面は表示されるのですが、たいていは 45 度ぐらい開けるとまた真っ暗になってしまいます。まあ、そもそもが、2017 年に購入したものなので、古くてびっくりされるかもしれません。まだ Intel の Core i7 が載っている時代の MacBook Pro で、ちょうどファンクション・キーが廃止されていた時代の代物です。

これは、たしか、当時すごく評判の悪い機種だと思ったのですが、ファンクション・キーだけならともかく、エスケープ・キーもなんか帯状のタッチパネルみたいなところに移ってしまっていました。ちなみに、個人的にはあまり不便は感じませんし、音量や画面の明るさなんかはスライダーが表示されて使い勝手はよかったです。エスケープ・キーはあまり使わないように思いましたが、使うとしたら vi を使うぐらいなので、その場合には、だいたい `C-[` を使うので、たまに使う程度なら困りませんでした。

それはともかく、アップデートも段々とされなくなって、一番ショックだったのは LMStudio か何かをインストールしようとしたら、古すぎてインストールできなかったので、もうそろそろ寿命かな？ と思ってはいました。

実際には去年あたりから、もう寿命だろうと思って MacBook Air を買っておいたのですが、なんか自分の用途には普通に使えているし、PC の移行が面倒なので、せっかく買った MacBook Air も一年以上死蔵されることになりました。

それが、いよいよ調子がわるくなったので、まだ動いているうちに新しい去年買った MacBook Air に移行したのでした。もっとも、駄目になったのは Lid なので、プロジェクターとかテレビにつなげば使えそうではありますが、廃棄前に SSD のデータを消去する作業が残っているので、本当に動かなくなってからでは手遅れになってしまいます。それで、一大決心をして、新しい(でも去年買ったものです) MacBook に引っ越すことになりました。

ファイルは昨日のうちにコピーをとったので、すぐに新しい MacBook を起動すればよかったのですが、セロハンとか保護のための紙をとりさって Lid を開けてもうんともすんともいいません。真っ暗です。
通常は、Lid をあけるやいなや「ジャーーーン！！」といかにもな音がして林檎のマークが表示されるのですが、そのままです。これはどうやら死蔵している間にバッテリーが切れてしまったようでした。

正直なところをいうと、こういった新品は、いつでも Lid をあけると景気よく起動するものだと思ったのですが、こういうのもバッテリー切れというのがあるのですね……。

それで、なんか、すごく格好がわるいのですが、まずは充電をすることにしました。

しばらく充電をしていると、いきなり「ジャーーーン！！」といいだしてきたので、じゃあ、充電しながらセットアップでもしようかと思っていたら、なんか、画面に各国語で「こんにちは」が表示されていました。いや、これが「真の新品」ならわくわくものなんでしょうが、なんか、みていて、みじめな気分になっていました。いや、当の MacBook にしても、みじめなことこの上なかったでしょう。ちょっとかわいそうになってきました。

こういう物言いは、ちょっと老人くさすぎますが、昔なら、新しい PC なんかを手にしたら、もう、その日のうちにセットアップしたものです。新しい PC やら 新しい OS やら、わくわくしながらセットアップしたものですが、なんか、最近はすっかりそういうのに「ときめく」気持もなくなってしまって、むしろ、「動いているから、古いのを使えばいいかあ」という感じで、ぐずぐず古いものを使っていたりします。

### ログインするまで

とりあえず、起動するまでにいろいろと質問に答えないといけません。

言語はもちろん日本語です。ちなみに子供は `en_US` にしているのですが、
なんか、イキりもいいかげんにして欲しいものです。なんか、たまに子供の MacBook を見る際に
まったく操作できません。というか、拡散系の AI さんなみに、文字を読んでないで、
全体の雰囲気みたいなのをみて操作しているので、いきなり外国の街角に放り出されたみたいになってしまいます。

あとは、おぼえている範囲でいうと、Siri はいらないです、iCloud も使いませんとかいう感じです。

本当は Apple のアカウントもログインしたくないのですが、色々支障がでるのでこれはログインしておきました。

あと、地域とか聞かれましたが、なんか設定がうまくいきませんでした。
なんかへましたのかもしれないです。気がついたら PDT かなんかでした。

### ログイン後の設定

私には変な癖があって、スクロールがなんか普通の人と逆みたいなので、タッチパネルの設定でスクロールの向きを変えます。あと、時間が PDT だったので、直しました。時刻の直し方がわからないので、とりえず、`sudo date` コマンドで直しました。それでも、結局 PDT のままに、時刻だけ JST にしてもだめなので、結局検索してタイムゾーンふくめて GUI で直しましたが。

あとは、Dock ですね。Dock については名言があって「Dock なんて飾りです。偉い人にはそれが……」とかいう感じだったのですが、まあ名言関係なく、Dock が狭い画面上にあるのは邪魔なので、普段は隠れているように設定しました。なんか、他に、昔 MacOS ではなかった Desktop に表示されているカレンダーやら天気予報やらがありましたが、それも出てこないようにしました。あれって、結局気がきいているようで、他のウィンドウに隠れているので、あまり嬉しくありません。

### アップデート

アプリを入れるまえに、発売されてから一年以上たっているので、アップデートをすることにします。かなり時間がかかりました。

### Xcode

これで晴れてアプリ類をいれることができますが、まずは Xcode です。やっぱり C とか C++ のコンパイラはあったほうがいいですから。

ちなみに、今回は brew はいれませんでした。面倒なので、それにそもそもが UNIX 準拠の OS なので、まあ、なくてもなんとかはなりますので……。

ただ、brew を入れないと、gcc はドライバは入っていますが、コンパイラ本体は Clang なんですよね。競プロなんだかだと、gcc のほうが面倒はないのですが、まあ、Clang で競プロやるのも慣れてしまったのと、まだまだ、そういうレベルではないので、どうしてもというわけではありません。

それよりも python がシステムのはちょっと古いのとパッケージのインストールにいつも失敗するので、ちょっと迷ってはいるところです。まあ、でもすぐにというわけでもないので、とりあえず、今日は Xcode だけで……。

### web ブラウザ

MacOS なので、Safari がありますが、どっぷりと Google 様のエコシステムにとりこまれているので、Google Chrome を入れないわけにはいきません。まあ、入れてしまえば、いろいろ便利なんですけどね。ちなみに私は拡張機能は使ってません。なんか面倒なので。

### テキストエディタ

MacOS には最初から Vim が入っていますが、それはそれとして、普段づかいのテキストエディタも入れたくなります。

私の場合は Emacs なんですが、brew に依存していない方の Emacs を入れます。

ちなみに、私の「宗派」ですが、vi も Emacs も普通に使います。最近は一つのドライブになんでもかんでもインストールしてしまいますが、昔は `/usr/local` が別のディスクだったりすることも普通にあって、そうすると、起動時に失敗すると (たとえば `fstab` を壊したとか) Emacs が使えなかったりしますし、`/etc` の下のファイルはちょっと Emacs では編集したくなかったりで、両方をおぼえました。

そういえば、昔助手だった頃に Solaris のお守りを押し付けられて、管理者の助教授 (だから、そういう時代の話です) が `/etc/passwd~` とかいうのを `/etc` の下に残していたりしたので、ちょっとイラッとしたことがあります (というか、お守りを押し付けたのはその助教授なので、殺意もわきましたが)。

とはいっても、 vi も Curses ライブラリを使うので、`/lib` のあるディスクがこけた。あるいは、使えるのが `/bin` だけという状況になったら、最後は `/bin/ed` しか使えないのですが、最近は USB メモリからブートとか、インストール・ディスクのライブシステムが利用できたりできるので、そういったことを気にすることもないのかもしれません。

で、Emacs を入れますが、いままで使っていたのが、27.2 で、これは 30.2 なので、隔世の感があります。Emacs のパッケージとしては SKK だけとりあえずいれておきました。

かな漢字変換としては、どうなのかわかりませんが、専門用語が多かったりする文章を書く場合には、むしろ能率がよかったりします。

### TeXlive

ちなみに、いままでつかっていた texlive は texlive 2017 でした。古いですね。

### その他

まだ入れていませんが、Go と Rust の処理系はインストールするつもりです。ただ、今日は疲れたので、あとでにしようと思います。あと、MS Teams とかもいれないといけないのですが、デスクトップ・アプリは面倒なので入れないですませたいです。

### 最後に

一月ちかくお休みしていて、突然に MacBook Air のセットアップ記で、唐突な感じでしたが、忘れないうちにと思ったので、書きました。個人的にはもう少し休みたいなと思うのですが、別に誰かに頼まれたわけでもないので、永遠に休んでも困る人はいないんじゃないかと思いますが、こうしてたまに書いてみると、なんか調子がいいので、そろそろ復帰したいと思います。

まあ、とりあえずは、お休みの間のことを書かないといけませんね。本来的には順番が逆なんですが。
